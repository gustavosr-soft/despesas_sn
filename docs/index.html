Visão geral

O Sistema de Despesas é uma aplicação web que substitui a planilha mensal de despesas. Ele roda em um computador (o servidor) e os demais acessam pelo navegador — nada precisa ser instalado nos outros computadores.

Lançamentos

Registre despesas por dia com descrição, categoria e valor. Vários lançamentos no mesmo dia, edição e exclusão com restauração.

Relatórios

Excel com fórmulas, PDF em A4 paisagem e impressão direta pelo navegador. Totais por categoria e total geral.

Controle de acesso

3 perfis (Administrador, Lançador, Consulta), bloqueio por tentativas, sessão com expiração e auditoria completa.

Backup automático

Backup diário configurável com retenção. Restauração via script com proteção do banco atual.

Instalação rápida

Um único script faz tudo

O PREPARAR_SERVIDOR.bat instala dependências, cria o administrador, libera o firewall e configura o início automático silencioso.

  1. Instale o Python marcando "Add python.exe to PATH"
  2. Copie a pasta do sistema para o servidor (ex.: C:\Despesas)
  3. Clique com o botão direito em PREPARAR_SERVIDOR.bat → Executar como administrador
  4. Siga as instruções na tela
  5. Acesse pelo navegador: http://IP-DO-SERVIDOR:8080

Instalação detalhada

1. Instalar o Python

Baixe em python.org/downloads. Na primeira tela do instalador:

  • Marque "Add python.exe to PATH"
  • Marque "Install for all users" (recomendado)

Para verificar se instalou corretamente, abra o Prompt de Comando e digite:

python --version

Deve mostrar algo como Python 3.11.9.

2. Copiar os arquivos

Copie toda a pasta do sistema para um disco local do servidor. Exemplo:

C:\Despesas\

Atenção

O banco de dados ficará dentro desta pasta. Não compartilhe essa pasta na rede. Os outros computadores acessam pelo navegador, não pelos arquivos. O SQLite não funciona de forma confiável em pastas de rede.

3. Ajustar a configuração (opcional)

Abra o config.ini no Bloco de Notas. Os ajustes mais comuns:

  • Porta: padrão 8080. Se já estiver em uso, mude para outra (ex.: 8081)
  • Pasta de backup: troque para outro disco (ex.: E:\BackupDespesas)
  • Nome da empresa: aparece nos relatórios

4. Instalar dependências

Clique com o botão direito em INSTALAR.bat → Executar como administrador.

O script irá:

  1. Encontrar o Python instalado
  2. Criar o ambiente virtual (.venv)
  3. Instalar Flask, Waitress, openpyxl e ReportLab
  4. Criar o banco de dados
  5. Pedir nome e senha do administrador (mínimo 8 caracteres)
  6. Liberar a porta no Firewall do Windows

Instalação offline (sem internet no servidor)

Em outro PC com internet e mesma versão do Python:

pip download -r requirements.txt -d pacotes

Copie a pasta pacotes para junto do INSTALAR.bat. Ele detecta e usa automaticamente.

5. Iniciar o servidor

ModoComandoDescrição
Com janelaINICIAR.batJanela visível com mensagens do servidor

6. Acessar

Ao iniciar, o servidor mostra:

Neste computador:    http://localhost:8080
Outros computadores: http://192.168.x.x:8080

Nos outros computadores da rede, abra o navegador e digite o endereço http://192.168.x.x:8080 (substitua pelo IP real do servidor). Salve nos favoritos.

Rede e Firewall

Recomendações

  • Fixe o IP do servidor (ou reserve no roteador/DHCP) para o endereço não mudar
  • Mantenha o servidor ligado e sem suspensão automática durante o expediente
  • A rede do servidor deve estar como "Privada" (Configurações → Rede)
  • O acesso é por HTTP simples — adequado para rede interna confiável. Não exponha para a internet

Se os outros PCs não acessarem

  1. Rode LIBERAR_FIREWALL.bat como administrador
  2. Confira se a rede está como "Privada"
  3. Teste http://IP:8080/saude — deve mostrar ok
  4. Tente desativar temporariamente o antivírus/firewall de terceiros

Uso do sistema

Tela do mês

A tela principal reproduz o formato da planilha original: uma linha por lançamento, o valor na coluna da respectiva categoria, linha TOTAIS por categoria e TOTAL GERAL do mês. Os totais são sempre calculados pelo sistema.

Novo lançamento

Preencha: data, descrição, categoria e valor. O valor aceita os formatos:

  • 1.234,56 (com ponto de milhar)
  • 1234,56 (sem ponto)
  • 1234.56 (ponto como decimal)

Editar e excluir

Links ao lado de cada linha. A exclusão é lógica: o lançamento sai dos totais mas fica no histórico. O administrador pode restaurar (rodapé do mês → "Ver lançamentos excluídos").

Se duas pessoas editarem o mesmo lançamento ao mesmo tempo, a segunda recebe um aviso e nada é sobrescrito sem querer.

Navegação entre meses

Use as setas para avançar/voltar, ou escolha mês/ano e clique em Ir.

Perfis de acesso

Administrador

Acesso total: usuários, categorias, backup, auditoria e restauração de lançamentos excluídos.

Lançador

Cria lançamentos; edita e exclui apenas os que ele mesmo criou. Não acessa configurações.

Consulta

Visualiza os meses e gera relatórios (Excel, PDF, impressão). Não altera nada.

Usuário novo ou com senha redefinida é obrigado a trocar a senha no primeiro acesso. A senha provisória é definida pelo administrador no menu Usuários.

Categorias

Cada categoria ativa vira uma coluna na tela do mês e nos relatórios. O administrador pode:

  • Criar novas categorias
  • Renomear (altera inclusive nos meses anteriores)
  • Reordenar (setas para mover)
  • Desativar (a categoria some de novos meses, mas continua aparecendo onde foi usada)

Categorias padrão:

Funcionários · Impostos · Imobilizados · Serviços · Manutenção · Aluguel · Outros · Veículos

Pelo menos uma categoria deve permanecer ativa.

Sobre a impressão

O botão Imprimir abre uma nova aba com o relatório formatado e chama automaticamente a janela de impressão do navegador/Windows no computador de quem clicou. Escolha a impressora e confirme. Se a janela não abrir, use o botão "Imprimir" da própria página, ou abra o PDF e imprima por lá.

Backup e restauração

Backup automático

  • 1 por dia a partir das 22:00 (configurável no config.ini)
  • Mantém os 30 backups mais recentes
  • Funciona mesmo durante o uso do sistema (usa a API de backup do SQLite)
  • Se o servidor estiver desligado no horário, faz o backup ao ligar

Backup manual

Menu Backup → Fazer backup agora, ou rode BACKUP_AGORA.bat.

Restaurar um backup

  1. Pare o servidor: rode PARAR_SERVIDOR.bat
  2. Rode RESTAURAR_BACKUP.bat e informe o nome do arquivo de backup
  3. Inicie o servidor novamente: INICIAR.bat

O banco anterior é guardado automaticamente em dados\antes_restauracao_*.db.

Recomendação importante

Troque a pasta de backup para outro disco no config.ini (ex.: E:\BackupDespesas). Backup no mesmo disco do servidor não protege contra defeito do disco. Copie também, de vez em quando, a pasta de backups para fora do servidor.

ComponenteFunção
Flask 3.xFramework web (rotas, templates, sessão)
WaitressServidor WSGI de produção, multi-thread
SQLiteBanco de dados embutido (WAL mode, sem instalação)

O banco é acessado somente pelo processo do servidor. Os clientes usam apenas o navegador. Concorrência é tratada com transações BEGIN IMMEDIATE e busy_timeout.

Testes

O sistema inclui 67 testes automatizados cobrindo:

  • Parsing e formatação de valores monetários
  • Regras de negócio (criação, edição, exclusão, permissões)
  • Rotas web (login, CSRF, sessão, acesso por perfil)
  • Relatórios Excel (fórmulas recalculadas) e PDF (paginação)
  • Backup e restauração
  • Concorrência: 8 usuários simultâneos em servidor real Waitress
# Ativar o ambiente virtual
.venv\Scripts\activate

# Rodar todos os testes
python -m pytest tests/ -v

Atualização

  1. Pare o servidor: PARAR_SERVIDOR.bat
  2. Faça um backup: BACKUP_AGORA.bat
  3. Copie os arquivos novos por cima (mantenha as pastas dados\, backups\ e o config.ini)
  4. Inicie novamente: INICIAR.bat
